WORKOUT_ROUTINE API

DESCRIPTION:
The Workout Routine REST API is a backend web service built with Django and Django REST Framework that allows users to register,
authenticate securely using token-based authentication, and manage their personal workout logs. 
Users can create, view, update, and delete workout sessions categorized by training split (Push, Pull, Legs, Cardio)along with dates and session notes

PROJECT OBJECTIVES:
To build a secure REST API where users can register, log in with token authentication, and easily create, view, update, and delete their own daily workout sessions. 
It ensures each user's workout data stays private and well-organized.

TECHNOLOGIES USED:
* Djangorestframework
* DRF TokenAuthentication
* CRUD operations
* Database-SQLite
* Github
